# CV-in-mins

A fast, simple CV/Resume builder that helps you create professional resumes in minutes.

## Features

- Multi-step form for easy data entry (Personal Info, Skills, Experience, Education, Others)
- Multiple CV templates (Minimalist & Modern)
- Customizable accent colors
- Print/Download as PDF
- Data persists in localStorage (24-hour cache)
- Responsive design

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Zustand (state management)
- React Hook Form + Zod (validation)
- Radix UI (accessible components)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
